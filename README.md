Fothos - Galería Multimedia Personal



Este (además de ser mi primer proyecto "serio"), es un proyecto para la clase de programación en ambientes móviles con .NET MAUI. Consiste en una galería multimedia que permite tomar fotos o elegirlas de la galería, con persistencia de datos local usando SQLite.



\## Hecho por

Angiee Karoline Galvis Tarazona



\## 🚀 Funcionalidades

\* Login con contraseña hasheada (SHA256).

\* Captura de fotos con cámara y selección desde galería.

\* Gestión de permisos (cámara y almacenamiento).

\* Base de datos local (SQLite) para guardar los metadatos.

\* Galería con vista de tarjetas (CollectionView) y vista de estado vacío (EmptyView).

\* Pantalla de detalle para Editar y Eliminar fotos.

\* Compartir imágenes con otras apps.
